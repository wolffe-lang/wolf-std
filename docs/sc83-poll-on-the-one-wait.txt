## Prediction

The original prediction was committed at cbe64e4 before tests or production edits. Its intentional refinements retain modify/remove's error rows and the Windows narrow fallback, and correct the cost points from 1/64/1,000 to 1/64/256.

- Keep every public poll signature. Open one readiness set lazily per Waiter; change registrations in place, harvest once, close the set without closing the caller's handles. An unsupported set-open error row selects os_wait_ready. Return each ready key once in runtime order, explicitly unspecified for a persistent set. Do not sort or scan held keys on that path.
- Retire files+sockets, sockets+meanings, socket WRITE and files without meanings on serving hosts. Return READ/WRITE/HANGUP/ERROR facts unchanged and a signal meaning beside ready handles, never instead of them. Shape errors remain invalid before the host.
- A waiter holds at most 256 entries. Registration 257 is io without insertion or key loss; invalid shape/duplicate precede capacity. The capacity refusal makes no host call and does not replace os_error's prior result. Removing an entry releases its key.
- modify/remove keep {invalid, io}. Explicitly handle os_ready_set's unsupported as io: a set that opened on a serving host cannot meet it there. set_mutation checks that fact directly, lifecycle changes, persistence across 100 waits and handle-close removal.
- net.write_some(mut Socket, List[byte]) -> int ! {busy, closed, invalid, io} delegates one non-parking send. Empty checks the handle and returns 0; non-empty takes a prefix or busy. No deadline budget applies. invalid remains for the wrong-width FFI shape, unreachable in typed byte lists.
- unix.Credentials {pid, uid, gid} and unix.peer_credentials(Socket) -> Credentials ! {io, unsupported} delegate net_peer_cred. No queue abstraction or write-all wrapper is introduced.

Expected steady-state costs at 1, 64 and 256 handles: native kernel-only sets cost O(ready) plus O(ready) std conversion; polled entries add O(polled) and one poll. Checked sets scan O(N), respectively 1/64/256 entries. The one-shot fallback builds up to 2N elements and duplicates O(N) descriptors. Adds still scan keys to preserve duplicate/lowest-free-key rules; that does not make waits scan them. These are contract-based cost predictions, not timing benchmarks.

### Comptime posture

net/comptime_refuses_write_some keeps fail(E0701) as the reachable normative check. Both compiler tiers actually refuse List construction at resolve, before the send's barrier: [type.list.lit.value], spec/10-types.md §12, and the closed wolf-lang#101 document the current-edition scalar CTFE limit. The released interpreter independently refuses the probe comptime fn at run. Neither is claimed as a measurement of the send's own comptime sandbox barrier. The collector pins these named postures instead of pretending the builtin was reached. docs/sc83-witness/comptime-list-limit.txt is the public explanation; no new upstream issue is needed. The same limitation is stated on poll.open's pure List-based constructor.

### Host-dependent rows and merge gates

The focused runner has 24 rows, including the corrected term/pty_child, pure constructor/shape guards and a white-box fallback-registration regression, plus eight protocol/fixture unit checks. The documentation capability policy was seen red at 9874993 before poll joined the Exec facades (doc-capability-policy exit=101). Every admitted block must still execute on at least one lane; pure_rows independently pins pure construction, constants and pre-host shape guards on all three machines. The final gauntlet separately runs the whole standard suite, doc examples, formatting, lint, Rust checks and numeric/oracle gates.

- term/pty_child: the spawn map itself gives no controlling terminal, but a shell may take the mapped slave after exec. The row accepts only a normal read-end report with status 0, or a reported controlling terminal followed by SIGHUP and pipe EOF. Actual observations go to stderr. It normalizes CR LF and does not assume unchanged shell terminal attributes. This corrects the row/doc behind #147, not os_spawn_session.
- poll/pty_hangup: the master's final read is io on Linux and eof on macOS; both must report READ|HANGUP. The first wake may already carry hangup, so only its READ bit is required.
- poll/error_hangup: a pipe's write end with all readers gone carries ERROR on Linux, HANGUP on macOS, together with every requested interest. The read end carries READ|HANGUP.
- unix peer credentials: effective ids remain after close; Linux retains pid, macOS gives -1 after close. The forked client stays connected through an acknowledgement before the pid is checked. No different-uid client is claimed; checked loudly skips its unsupported fork and is covered by the same-process credential row.
- Socket/pty partial counts and buffer capacities are host-dependent; tests assert counts, bytes, busy and recovery, not a Linux capacity. Positive deadlines may finish late but never early.
- Windows retains only the existing socket-READ/no-meaning and empty-deadline fallback. Fallback adds validate fs handles with non-consuming metadata and net handles with a zero-deadline look before publishing a key; a forced-fallback regression was red on all three tiers at 1628818 before that fix. Its first correction at 9081498 exposed metadata's wider error row on both compiler tiers; 20e438a maps those validation failures to the existing io and satisfies fallback_validation plus pure_rows on all three released Mac tiers. These validations add the delegate's fs/net capability respectively, not a new error tag. The pty-child row only accepts the host's unsupported branch on Windows; a serving-host refusal is a test failure. Wide readiness, Unix and pty legs explicitly report their unavailable host posture. FreeBSD is described only by the runtime contract, not claimed as a tested std lane. A SKIP is never a serving-tier measurement.

Before merge require hosted tier all: rig AND gates on Ubuntu, macOS and Windows. The usual tier full omits the macOS rig and is not sufficient for these process/socket/timing rows.     WOLF_RT_LIB="$MUSL_RUNTIME" "$WOLF" build main.lu --std-root "$STD" --linker "$STATIC_MUSL_CC" -o probe

STATIC_MUSL_CC must be a cc-shaped executable wrapper invoking the installed musl C driver with -static, not a raw ld or shell text passed as --linker.
