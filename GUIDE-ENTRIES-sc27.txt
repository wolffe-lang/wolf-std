## 2026-08-29 (sc27) — the divergences re-measure; a predicted zero, measured

- Write the drift PREDICTION down before the run, clause by clause,
  and make zero a first-class prediction: sc27 read two changelogs and
  one merge span, grepped the corpus for every new surface (str `+`,
  comma binders, destructuring, list slices, `#![`), predicted
  ZERO/ZERO over 365 rows and measured ZERO/ZERO. A gauntlet that
  confirms a written zero is evidence; the same gauntlet run "to see
  what happens" is noise. The reconciliation is the deliverable.
- A bump can carry TWO releases and stay one honest step when the
  skipped release is invisible to the rig: 0.1.16/is27 renders
  line:col on the HUMAN doors only and declares --json byte-stable, so
  sc26's deliberate non-chase cost nothing and sc27 read two release
  notes instead of one. Release notes first, PER RELEASE, before a
  single measurement — the reading is what turns "re-measure
  everything" into "confirm three sentences".
- The pairing line can lawfully name a release one BEHIND the binary
  staged beside it: wolf @ 0a5c1af pairs "lupin 0.1.16" while the rig
  stages 0.1.17, because the pairing stamp is cut when the compiler
  sha is, not when the interpreter releases. Report-never-gate
  (F-0064) has a corollary: record the nuance AT the bump, so the
  next doctor reader spends zero minutes on it.
- A heal has a BOUNDARY and the boundary is measured, not assumed:
  0.1.17's #50 fix makes `char` a copy value (the issue's reproducer
  prints `xx` exit 0 on all three lanes), and the sc22 cursor-struct
  rule (`Rd { b: bs, end: bs.len }` is E1001 / use-after-move) is
  UNMOVED — char was the one scalar mis-classed as a move value.
  Re-probe the neighboring guidance when a fix lands; note the
  boundary; never rewrite the old entry's history.
- A residue list is an economy, and it shrinks one measured row at a
  time: F-0018's row 6 (str + str, E0409 under wolfc since sc03)
  healed at s128 (D62) — measured three-lane with the mixes still
  E0409 by ruling — while the tuple-list probe sharpened WITHOUT
  moving (s128 destructures tuples; it does not instantiate
  `List[(int, int)]`, the same resolve refusal at a third pin). Probe
  a residue at every bump that plausibly touches it; date the
  non-movement with the same care as the heal.
- Measure the new surface, adopt none of it, file the candidates: the
  sprint that re-measures is not the sprint that rewrites. sc27's
  candidate list (str `+` at the 24 "{a}{b}" sites — cost-equal by
  [type.str.concat.cost], so purely cosmetic; destructuring at the
  `.0`/`.1` sites; D63 binders in fixtures; list slices priced against
  the fresh-copy anchor) is the next contract's input, and `+=` in a
  loop stays quadratic by the anchor's own words — strbuf remains the
  builder no matter how pretty the operator is.
- The third measurement of a standing divergence is one staged dir and
  one conform-run away: the gauntlet re-observes a `divergent(…)` row
  wholesale, but the UPSTREAM comment wants the raw record — re-run
  the staged entry (`target/stage/<row>/`, `--std-root std --json`)
  and paste the observation. Byte-identical three sprints running is
  itself the finding; say "expected: no net/process commit in the
  span" so the issue reads a mechanism, not a ritual.
